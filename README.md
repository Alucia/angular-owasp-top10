# Angular OWASP Top 10 – Security Best Practices

Este repositorio demuestra vulnerabilidades comunes del OWASP Top 10
en aplicaciones Angular y cómo mitigarlas correctamente.

## Contenido
- Insecure Angular App (ejemplos vulnerables)
- Secure Angular App (buenas prácticas)
- Checklist de seguridad Angular
- Material para charla técnica

## Requisitos
- Node.js >= 18
- Angular >= 17

## Disclaimer
Este proyecto es solo educativo.
